# Voidline — téléchargements

Voidline est un jeu d'action coopératif en 3D (façon MOBA / Hades) fait avec Godot, en cours de développement.
Ce dépôt ne contient que **les versions jouables** ; le code du jeu est privé.

## Télécharger

👉 **[Dernière version](../../releases/latest)** : télécharger `Voidline-<version>-windows.zip` (rubrique *Assets*), le décompresser, lancer `Voidline.exe`.

- **Windows 10 / 11, 64 bits**, carte graphique compatible DirectX 12 ou Vulkan.
- Au premier lancement, Windows peut afficher « Windows a protégé votre ordinateur » (le jeu n'est pas signé) :
  **Informations complémentaires → Exécuter quand même**.
- Si ça saccade : touche **O** en jeu (qualité graphique), ou Options → Image.

## Le jeu

Une expédition coopérative au cœur de la Faille : ton héros et deux alliés pilotés par l'IA traversent quatre zones
(nids à détruire, gardiens, marchands, bonus à choisir) jusqu'au boss final. Quatre héros, le Pacte pour corser les
parties, l'Autel pour des améliorations permanentes. Le mode Duel (1 contre 1 sur une lane) est aussi là.

Touches principales : clic droit (bouger, attaquer), Q W E (sorts), R (ultime), Maj (esquive), 1 2 3 (bonus),
P (boutique), Échap (pause et options). Le détail est dans le jeu : Options → Contrôles.

Crédits et licences (musique de Kevin MacLeod, sons, modèles, icônes, moteur Godot) : menu principal → Crédits.
